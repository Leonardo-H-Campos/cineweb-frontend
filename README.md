🎬 CineWeb — Sistema de Gerenciamento de Cinema

Projeto desenvolvido como atividade prática, com o objetivo de criar um sistema simples para gerenciamento de filmes, salas, sessões e venda de ingressos.
A aplicação foi construída utilizando React + TypeScript + Vite e um backend simulado com JSON Server.

📌 Funcionalidades do Sistema
🎞️ Filmes

Cadastro de filmes com título, sinopse, duração, gênero e classificação.

Listagem dos filmes cadastrados.

Exclusão de filmes.

🏟️ Salas

Cadastro de salas com número e capacidade.

Listagem das salas cadastradas.

Exclusão de salas.

🎥 Sessões

Agendamento de sessões informando filme, sala e horário.

Exibição das sessões agendadas.

Visualização do número de ingressos vendidos (em tempo real).

🎟️ Vendas de Ingressos

Tela dedicada para venda de ingressos.

Registro de tipo de ingresso (inteira ou meia).

Atualização automática da quantidade de ingressos vendidos.

Controle de capacidade da sala.
